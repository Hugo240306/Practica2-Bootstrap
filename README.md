# 🌐 Práctica 2: Deseño de interfaces web

Desarrollo de una web responsive para una comunidad tecnológica, utilizando **Bootstrap 5.3**, HTML, CSS y JavaScript. Proyecto realizado en equipo aplicando metodología **Scrum**, con planificación por sprints, diseño de wireframes y gestión mediante GitHub.

## 📖 Descripción del proyecto

Web responsive pensada para una comunidad tecnológica. El proyecto se ha desarrollado en equipo siguiendo Scrum: se planifica el trabajo por sprints, se diseñan wireframes y moodboard antes de maquetar, y todo el control de versiones se gestiona con GitHub.

## 🎯 Objetivos del Sprint 1

- [x] Definir la temática y el público objetivo
- [x] Crear el moodboard del proyecto
- [x] Diseñar los wireframes de las páginas principales
- [x] Definir la paleta de colores
- [ ] Maquetar la página de inicio con HTML5 semántico y Bootstrap
- [ ] Hacer que el diseño sea responsive (móvil, tablet y escritorio)
